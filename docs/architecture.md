## 核心流程

### 1. 每日岗位抓取流水线

```
招聘官网 → 抓取JD → 关键词过滤 → 简历匹配打分 → 四色块分类 → 写入飞书表
                          ↓
                   实习/硬件/供应链 → 自动剔除
```

**打分维度（满分100）：**
- 经验匹配度（40分）：JD关键词 vs 简历经历
- 技术栈匹配（30分）：Python/SQL/千川/直播运营等
- 薪资匹配（30分）：年薪 ≥18万 满分，15-18万 半分，<15万 0分

### 2. 邮件追踪流程

```
IMAP收邮件 → 正则识别类型 → 更新飞书表 → 飞书日历加事件
                ↓
         笔试/面试/通过/挂
```

## 设计原则

1. **无数据库**：全部用 JSON/CSV 文件存储，降低部署门槛
2. **无后端服务**：纯静态前端 + Python 脚本，不需要 Node/Java 服务
3. **可独立运行**：每个模块可以单独跑，也可以组合成流水线
4. **优先用现成工具**：飞书做表格/日历，不自己造轮子
